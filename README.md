# Flujo commit de Git

1. Traer los cambios
    ```bash
    git fetch
    git pull origin main

2. Estado actual del repositorio local
    ```bash
    git status

3. Agregar los cambios a capa staggin
    ```bash
    git add.
4. Generar el commit
    ```bash
    git commit -m "mi primer commit"
5. Empujar los cambios
    ```bash
    git push origin main
